# Contributing

Use the qualified Linux x86_64/Python3.13 tuple and actual hash locks. Run
`sh scripts/check.sh`; preserve source/wheel/sdist hashes and failure records.
Changes to temporal indexing, maturity, float policy or wire bytes require new
independent literal/Decimal oracles and regressions. Keep sklearn responsible
for the estimator; do not substitute a handwritten learner or claim guaranteed
coverage, model superiority, customers or production adoption. English and
Brazilian Portuguese documentation describe the same actual behavior.
